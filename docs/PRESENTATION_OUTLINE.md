# eBobo — konspekt prezentacji (≤10 slajdów)

## 1. Obietnica
eBobo: od sytuacji rodzica do świadczeń, kwoty i konkretnego kroku.

## 2. Problem
Rodzice nie wiedzą, *co* im przysługuje, *ile*, *gdzie* i *do kiedy* — formalności ZUS są rozproszone.

## 3. Wartość dla ZUS
Mniej błędnych wniosków, lepsza edukacja, prowadzenie do właściwego kanału (pracodawca / eZUS).

## 4. Jak działa
Ankieta / przykładowa sprawa → silnik 9 świadczeń → statusy A–E.

## 5. Kalkulator
Kontekst świadczenia, podstawa indywidualna, compare rodziców, bez lokalnych formuł.

## 6. Formalności
Dokumenty, terminy, ZUS vs pracodawca, oficjalne linki (bez wycofanych Z-3b/ZUR).

## 7. Silnik + AI
FastAPI `rules_version`; AI tylko wyjaśnia — nie przyznaje.

## 8. Testy i przykłady
S1–S7 syntetyczne; bez publikacji PDF spraw; ścieżka `/sample-cases`.

## 9. Architektura
Expo Web · REST · osobny BE · wersjonowanie reguł.

## 10. Potencjał i ograniczenia
Wdrożeniowo: API + reguły BE. Jawne: symulacje, brak decyzji ZUS, hosting demo.
